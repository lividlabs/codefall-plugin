# Changelog

Releases from 0.1.2 onward are generated by release-please from Conventional Commits. The entries
below were written by hand, before that was wired up.

Tags are bare version numbers (`0.1.2`), not `v`-prefixed, so they match the `ref` the marketplace
pins. A `v0.1.1` tag also exists from before that convention was settled.

## [0.1.1](https://github.com/lividlabs/codefall-plugin/compare/v0.1.0...v0.1.1) (2026-08-09)

### Bug Fixes

* resolve scaffold template paths against `${CLAUDE_PLUGIN_ROOT}` instead of bare relative paths,
  which left the plugin's install location ambiguous
* add `allowed-tools` (Read, Glob, Grep, AskUserQuestion) so reading bundled templates stops
  prompting; Write, Edit, and Bash are deliberately omitted
* stop offering gate options that would be refused — the language question was a menu listing
  unsupported profiles annotated "I would have to stop"
* recommend only what an ADR supports; the interview had invented a house opinion on monorepo
  layout that no ADR holds

## 0.1.0 (2026-08-08)

Initial release.

* `scaffold` — start a new project on the Clean Architecture + package-by-component stance: ratified
  ADRs, scoped `AGENTS.md` files, optional project files and boundary lint
* Stack-agnostic ADR core (ADR-001 Clean Architecture, ADR-002 package-by-component) plus a
  `typescript-react` surface profile supplying ADR-003 through ADR-005
* Describe-and-match gate that refuses surfaces with no profile rather than improvising ADRs
